# ESigner.Chrome.TCT Extension

## Giới thiệu

Đây là extension ký điện tử ESigner.Chrome.TCT, được nâng cấp để tương thích với Manifest V3 của Chrome. Extension này cho phép bạn ký điện tử các tài liệu trên trang web thuedientu.gdt.gov.vn và các trang con của nó.

## Cài đặt

1.  **Tải extension:** Tải file .zip của extension từ [link tải xuống] (bạn sẽ cần cung cấp link này).
2.  **Giải nén:** Giải nén file .zip đã tải về vào một thư mục trên máy tính của bạn.
3.  **Mở trang quản lý extension của Chrome:** Mở trình duyệt Chrome và truy cập vào `chrome://extensions`.
4.  **Bật chế độ nhà phát triển:** Ở góc trên bên phải của trang, bật "Chế độ dành cho nhà phát triển".
5.  **Tải extension đã giải nén:** Nhấp vào nút "Tải tiện ích đã giải nén" và chọn thư mục mà bạn đã giải nén extension ở bước 2.

## Sử dụng

Sau khi cài đặt, extension sẽ tự động được kích hoạt khi bạn truy cập trang web [thuedientu.gdt.gov.vn](https://thuedientu.gdt.gov.vn). Bạn có thể sử dụng các chức năng ký điện tử như bình thường.

## Gỡ cài đặt

1.  **Mở trang quản lý extension của Chrome:** Mở trình duyệt Chrome và truy cập vào `chrome://extensions`.
2.  **Tìm extension:** Tìm extension ESigner.Chrome.TCT trong danh sách.
3.  **Xóa extension:** Nhấp vào nút "Xóa" để gỡ cài đặt extension.

## Lưu ý

* Extension này chỉ hoạt động trên các trang web được cho phép trong file `manifest.json`, cụ thể là `*://*.thuedientu.gdt.gov.vn/*`.
* Nếu bạn gặp bất kỳ lỗi nào, vui lòng kiểm tra lại xem bạn đã cài đặt đúng cách chưa và đảm bảo rằng bạn đang ở trên trang web được hỗ trợ.
